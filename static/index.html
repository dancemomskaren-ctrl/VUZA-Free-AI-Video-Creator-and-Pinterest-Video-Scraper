VUZA

Zero-cost automated video generation

Enter a video idea or narration script — VUZA automatically breaks it into scenes, generates cinematic visuals with Seedream, adds a free AI voiceover, renders subtitles, and assembles a vertical short-form video.

Current defaults: Suspense/thriller template, Seedream 4.5 AI images, English (US) voiceover, high-retention subtitles, 9:16 vertical output.

Works with OpenRouter / OpenAI-compatible APIs
Runs locally, even on low-spec machines

How to use: Add your AI text key and Seedream image key in API Settings, then enter a topic, generate a script, and hit "Generate Video".

🔒 All keys are stored only in your browser's localStorage — they are never sent anywhere except the API endpoints you configure.

AI Brain (OpenRouter / DeepSeek / OpenAI-compatible)

DeepSeek official: URL https://api.deepseek.com, model deepseek-v4-pro. OpenRouter: use the chat/completions URL, model is usually "vendor/model".

Seedream 4.5 Image Generation

AI image mode / auto video needs both the AI text key and Seedream 4.5; the Pollinations fallback is disabled by default.
